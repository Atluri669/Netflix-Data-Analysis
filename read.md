# Netflix Data Cleaning and Preparation

This project uses a Jupyter notebook to inspect and clean a Netflix titles dataset, then save the result as a CSV file.

## Files

- `Netflix Data Cleaning & Preparation.ipynb` - notebook containing the data-cleaning workflow.
- `Dataset.csv` - input dataset. Keep it in the same folder as the notebook.
- `Netflix_cleaned.csv` - cleaned output generated by the notebook.

## Requirements

- Python 3
- pandas
- Jupyter Notebook or JupyterLab

Install the required Python packages with:

```bash
python -m pip install pandas notebook
```

## How to run

1. Open a terminal in this folder.
2. Start Jupyter with `jupyter notebook`.
3. Open `Netflix Data Cleaning & Preparation.ipynb`.
4. Run the notebook cells from top to bottom.

The notebook reads `Dataset.csv` from the current working directory and writes `Netflix_cleaned.csv` there.

## Cleaning workflow

The notebook:

1. Loads and summarizes the dataset.
2. Checks for missing values and duplicate rows.
3. Strips whitespace from text and column names.
4. Standardizes selected text fields and fills selected missing text values with `Unknown`.
5. Attempts to convert `release_year` to a numeric value.
6. Exports the result to `Netflix_cleaned.csv` and reports the final shape and duplicate-row count.

## Dataset fields

The input includes fields such as `show_id`, `type`, `title`, `director`, `country`, `date_added`, `release_year`, `rating`, `duration`, and `listed_in`.
